Top Viva / Review Questions & Answers

          

            

              
Q1: How do you stay within the $25 student budget?

              
We use GitHub Container Registry (GHCR) instead of paid ECR, run Jenkins and Kubernetes (kind) locally on laptop RAM, use a static regional price table instead of paying $0.01/call for AWS Cost Explorer API, and enforce a $5 AWS Budget alarm + terraform destroy after every demo session.

            

            

              
Q2: What happens if two engineers click "Execute" at the same time?

              
The PostgreSQL state machine uses an atomic conditional update (UPDATE recommendations SET status='EXECUTING' WHERE id=$1 AND status='APPROVED'). Only the first request acquires the lock; the second receives a conflict error.

            

            

              
Q3: What if an unattached EBS volume actually had needed data?

              
Before calling ec2:DeleteVolume, our Remediation Executor calls ec2:CreateSnapshot and logs the rollback_snapshot_id in audit_logs so the volume can be restored in one click.
